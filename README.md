# Finance Tracker

A personal finance management tool built with **Streamlit**, **Firebase
Firestore**, and **Google Gemini AI**. Upload bank statements, track spending,
detect duplicates, and get AI-powered insights into your finances.

The app lives in [`finance-app/`](finance-app/). Start there:
